A little help in the kitchen

This is DishNest 0.1.0, a development preview. Start with an empty private kitchen or explicitly load demo recipes. Add at least one recipe, assign it in Meal planner, and generate a shopping list. Use Settings to export a JSON backup before clearing data. If microphone recognition is unavailable, continue with touch controls. For timer alerts, allow notifications and check device battery restrictions. Use the GitHub support link below to report general problems. Issues are public: omit private recipes, photos, purchase receipts, Amazon account identifiers and other sensitive information. For private support or privacy/deletion help, email banksmi@mail.com. The publisher is O. Bankole. Final privacy and production-service details still need approval. No Amazon listing has been published.
