A little help in the kitchen

This is DishNest 0.1.0, a development preview. Start with an empty private kitchen or explicitly load demo recipes. Add at least one recipe, assign it in Meal planner, and generate a shopping list. Use Settings to export a JSON backup before clearing data. If microphone recognition is unavailable, continue with touch controls. For timer alerts, allow notifications and check device battery restrictions. No public support address or Amazon listing has been configured; the publisher must add both before submission.
