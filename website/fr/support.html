Aide et assistance

DishNest 0.1.0 est une version de développement. Commencez avec une cuisine vide ou ouvrez volontairement la cuisine de démonstration. Ajoutez une recette, attribuez-la à un repas dans le planning et créez une liste de courses. Exportez une sauvegarde dans les paramètres avant de supprimer vos données.

Si la reconnaissance vocale est indisponible, utilisez les commandes tactiles. Pour les alertes de minuteur, vérifiez les notifications et les restrictions de batterie. Les demandes générales sur GitHub sont publiques. N’y publiez pas de recettes privées, de photos, de reçus, d’identifiants Amazon ni d’autres informations sensibles. Pour une demande privée, de confidentialité ou de suppression, écrivez à banksmi@mail.com. L’éditeur est O. Bankole. DishNest n’a pas encore de fiche Amazon publique.
